# 观心 v0.2.0-demo

## 能力摘要

- 对外 stdio MCP 网关：知识检索、文本摘要、数据分析，固定只读范围，API Key 认证与租户隔离。
- PDF/DOCX 真实文本提取、切片预览与引用；Agent Data Analysis 自动生成 A2UI 图表。
- 持久化 Supervisor、公开网页研究、审批工作流与刷新/后端重启恢复。
- Python、前端和 Chromium 分层测试及 PR/main 全量 CI。

## 启动

准备 DeepSeek API Key 和 Ollama `bge-m3:latest`，按 README 配置后运行 `./scripts/start.sh`。
外部 MCP 客户端使用 `scripts/start-mcp-server.sh`；天气外部 Server 使用 `scripts/start-weather-mcp-server.sh`。
详细演示步骤参见 [Demo 手册](../demo-guide.md)。

## 验收

以 [验收报告](v0.2.0-demo-acceptance.md) 为准。全部门禁和真实场景通过前不发布标签或 GitHub Release。

## 已知边界

这是本地 Demo，不含生产部署、审计日志、限流、远程 MCP、账号数据库迁移、条件分支或并行 DAG。
扫描 PDF 不包含 OCR。登录账号/API Key 为进程内预设数据，管理型 Skill 的 users JSON 与认证账户不是同一套存储。
天气和研究依赖公网；研究提供预算和证据边界，不保证第三方响应时间或结果完整性。

发布时在 GitHub Release 正文补充已验证的合并提交及与前一发布版本的比较链接。
