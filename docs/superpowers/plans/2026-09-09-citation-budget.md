# 引用证据与搜索预算

沿用用户确认的下一步：主张—原文—链接审查与搜索预算，继续使用 Deep Agents 官方执行循环。

- 搜索预算按会话持久化，跨取消/继续/重启不重置。快速/自动最多 2 次请求、20 个已报告服务端动作；深度最多 4 次请求、40 个动作。首次搜索固定预算。串行准入防止并行调用绕过；未知用量保守暂停。请求数为硬限制，动作阈值只阻止后续请求，不承诺截断供应商内部调用。
- 仅对配置允许的 HTTPS 公共来源读取原文，限制响应大小、超时和重定向，拒绝私网及未在本会话搜索中出现的 URL。记录获取时间和内容哈希。
- 引用工具保存主张、URL、逐字摘录，检查摘录是否存在于实际获取的正文；不把文字匹配标记成语义支持。未取得原文/摘录不符明确返回失败。
- 线程状态及前端显示搜索余量和引用审查条目。语义状态始终为待人工审查，模型不能自行批准。
- 测试预算并发/失败/持久化、URL 边界、引用匹配与越权；最后运行真实研究样本和原生浏览器回归。
