# 用户查询统计看板

用户已确认：在聊天中直接展示用户统计卡片、角色分布条形图、活跃状态环形图及可折叠用户明细，沿用现有主题并适配窄屏。

## 数据与实现

`query_users` 在筛选后、分页前计算 `statistics`，包含总人数、角色人数、状态人数，并返回筛选条件。现有列表与分页字段保留。技能的角色图表字段复用全量筛选统计。`create_user` 的角色图表同样改用全量统计口径，不再只统计第一页。

筛选条件以字符串回传：技能层与存储层都把未填写的筛选条件归一化为空字符串，工具输出里的 `filters` 不会出现 `null`。

前端只对 `skill__query_users` 的有效成功结果使用独立看板组件。旧结果由当前页用户计算指标；分页不完整时明确标记本页口径。失败和无效结果保留原有工具展示。空结果不绘制占比图。使用现有 Recharts 绘制环形图，条形图同时显示人数与占比。

解析按字段降级，而不是整包丢弃：统计块缺失或与总数不一致时只丢掉统计块、看板退回本页口径；单条用户记录字段不全时只丢掉该条记录，不影响其余看板内容。

原生会话恢复后的工具消息经过相同渲染逻辑。用户进一步确认移除卡片下方的文字版描述。模型与界面之间用 `[看板]` 前缀约定：纯复述统计数字时正文以该前缀开头并立即结束，界面隐藏这条正文；要在看板之外补充信息时不带该前缀，正常显示。界面只在本轮确有成功查询的看板时才隐藏该正文，查询失败时即使带前缀也保留，且标记不会显示给用户。模型报出的数字与看板不一致时视为错误信号，保留原文。包含其他工具的轮次及后续普通对话正常显示。

## 可用性前提

`query_users` 是只读技能且仅管理员可执行。种子配置默认启用它，因此全新安装开箱可用；种子只在租户配置不存在时写入，已有数据库的租户需要在「Agent 配置」手动勾选「查询用户列表」，否则工具不可调用。
