## 人工引用审查

复测成功读取 persistence 指南以及 interrupt、Command API 参考页，记录正文哈希、获取时间和最终 URL。读取失败的其他页面未记为已取得原文。

存在一条 Command 主张同时声称支持“单值”和“中断 ID 映射”，所选摘录却仅说明需与 interrupt 配合使用；该摘录只支持主张的一部分。另有 thread_id 摘录包含示例但片段在单词中间截断，可读性仍可改善。回答对“持久化需要 checkpointer”的开头表述过宽，虽然随后补充了 Store，仍应更准确限定为线程图状态持久化。

因此 **quote_match=true 只代表摘录确实出现在获取的正文中**。六条记录均保留 `requires_human_review`，不采信模型自行宣称的“已核实完毕”。当前没有人工批准操作，也没有自动蕴含判定。

## 成本和预算边界

复测主模型已知费用为 $0.01366416–0.02732831，两次搜索模型分别为 $0.00977489–0.01954978、$0.00999227–0.01998454，合计 **$0.03343132–0.06686263**。合计已报告 token 为 385,970。价格依据和峰谷区间沿用轨迹记录的当日价格口径；不含搜索服务费、Embedding 和未返回 usage 的失败请求，不能视为最终账单。

主模型 token 下降，但总耗时、搜索工作量与缓存条件不同，不能据此宣称总成本下降。这一轮增加了原文核对成本；需要后续重复样本才能判断性价比。

请求数是本地硬限制；动作阈值只检查是否允许下一次请求。复测第一次报告 18 个动作，尚低于 20，所以允许第二次，最终累计 30。这不是预算绕过，也不能称为“最多 20 次服务端动作”。失败或取消导致用量未知时不退款、不继续搜索；重启、继续和切换模式不重置首次确定的会话额度。
